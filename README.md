# 🤖 RestGen-AI

**RestGen-AI** is a beginner-friendly tool that helps you **instantly generate Spring Boot REST API code**. It automates the creation of essential components like **Controllers, Services, Repositories, and Entity classes** based on your input.

This tool is perfect for **Java beginners**, as it helps you learn by generating ready-to-use project structures, saves you time, and ensures a clean architectural foundation for your projects.

-----

## 🚀 Features

  * ✨ **Instant Code Generation** – Quickly generates a complete Spring Boot REST API project.
  * 🏗️ **Automated Structure** – Creates Controller, Service, Repository, and Entity classes automatically.
  * 🧑‍🎓 **Beginner-Friendly** – Simplifies the setup process, allowing new developers to focus on core logic.
  * 🧹 **Clean Architecture** – Follows best practices to provide a well-organized project scaffold.
  * ⏱️ **Time-Saving** – Reduces boilerplate coding, accelerating the development process.

-----

## 🏗️ Tech Stack

**Backend:** Java (Spring Boot)
**Frontend:** HTML, CSS, JavaScript
**Build Tool:** Maven / Gradle

## ⚙️ Installation & Setup

### 🔹 1. Clone the Repository

```bash
git clone https://github.com/Vinayak24Patil/RestGen-Ai.git
cd RestGen-Ai
```

### 🔹 2. Run the Application

  * You can run the application directly from your IDE (e.g., IntelliJ, Eclipse).
  * Alternatively, use Maven to build and run the project:

<!-- end list -->

```bash
# Build the project
./mvnw clean install

# Run the application
./mvnw spring-boot:run
```

-----

## 🎯 Usage

1.  Open the application in your browser (usually `http://localhost:8080`).
2.  Provide your desired inputs (e.g., entity name, fields).
3.  Click the "Generate" button to download your new Spring Boot project.
